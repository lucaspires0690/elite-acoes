Sobre Natura (NATU3)

Como Calcular o Preço Teto de NATU3 pelo Método Bazin

O Método Bazin, criado pelo investidor Décio Bazin, é uma abordagem educativa para estimar um preço teto de uma ação com base nos dividendos pagos. A ideia central é que o investidor defina um rendimento mínimo desejado — a taxa Bazin — e calcule quanto pagaria para obter esse retorno.

Fórmula: Preço Teto = Dividendos dos últimos 12 meses ÷ Taxa Bazin (6%).

Exemplo hipotético para ilustração — valores fictícios:

Suponha que NATU3 tenha distribuído R$ 1,20 em dividendos nos últimos 12 meses. Aplicando a fórmula: R$ 1,20 ÷ 0,06 = R$ 20,00. Esse seria o preço teto hipotético. Lembre-se: este é um exemplo fictício, não representa dados reais.

O método não considera outros fatores como valuation ou perspectivas futuras. É uma ferramenta entre várias para análise fundamentalista.
