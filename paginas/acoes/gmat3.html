Como Calcular o Preço Teto de GMAT3 pelo Método Bazin

O Método Bazin, criado pelo economista Décio Bazin, é uma abordagem educacional para estimar um preço teto de uma ação com base nos dividendos pagos. A lógica é simples: o investidor define uma taxa de retorno desejada (yield) e calcula quanto pagaria para obter esse rendimento.

Fórmula: Preço Teto = Dividendos dos últimos 12 meses ÷ Taxa Bazin

Para GMAT3, a taxa Bazin comumente utilizada é de 6% (0,06). O cálculo é puramente ilustrativo e não representa garantia de retorno.

Exemplo hipotético: Suponha que GMAT3 tenha pago R$ 1,20 em dividendos nos últimos 12 meses (valores fictícios). O preço teto seria R$ 1,20 ÷ 0,06 = R$ 20,00. Este número é apenas uma simulação educacional — não use como recomendação de compra.
