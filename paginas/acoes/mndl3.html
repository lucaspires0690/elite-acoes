Como Calcular o Preço Teto de MNDL3 pelo Método Bazin

O Método Bazin, criado pelo investidor Décio Bazin, é uma abordagem educativa para estimar um preço teto de uma ação com base nos dividendos pagos. A premissa é que o investidor define uma taxa de retorno desejada — no caso, 6% ao ano — e calcula quanto pagaria para obter esse rendimento.

Fórmula: Preço Teto = Dividendos dos últimos 12 meses ÷ Taxa Bazin (6%)

Exemplo hipotético para ilustração — valores fictícios: Se a Mundial distribuiu R$ 1,20 em dividendos nos últimos 12 meses, o preço teto seria R$ 1,20 ÷ 0,06 = R$ 20,00. Isso significa que, para um rendimento de 6% ao ano, o investidor pagaria no máximo R$ 20,00 por ação. Este é apenas um exemplo didático.
