Como Calcular o Preço Teto de GGPS3 pelo Método Bazin

O Método Bazin, criado pelo investidor Décio Bazin, é uma abordagem educativa para estimar um preço teto de uma ação com base nos dividendos pagos. A premissa é que o investidor busca um rendimento mínimo de 6% ao ano em proventos.

Fórmula: Preço Teto = Dividendos dos últimos 12 meses ÷ 0,06

Exemplo hipotético para ilustração — valores fictícios:
Se os dividendos anuais de GGPS3 fossem R$ 1,20 por ação, o preço teto seria R$ 20,00 (R$ 1,20 ÷ 0,06). Este cálculo não reflete dados reais atuais e serve apenas como demonstração do método.

O investidor pode usar essa ferramenta para comparar o preço teto com o preço de mercado atual, sempre lembrando que se trata de uma metodologia entre várias existentes.
