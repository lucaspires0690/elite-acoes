Como Calcular o Preço Teto de DESK3 pelo Método Bazin

O Método Bazin, criado pelo investidor Décio Bazin, é uma abordagem educativa para estimar um preço teto de uma ação com base nos dividendos pagos. A lógica é simples: o investidor define uma taxa de retorno desejada (yield) e calcula quanto pagaria para obter esse retorno.

Fórmula: Preço Teto = Dividendos dos últimos 12 meses ÷ Taxa Bazin (em decimal). Para DESK3, a taxa Bazin sugerida é de 6% ao ano (0,06).

Exemplo hipotético para ilustração — valores fictícios:

Se DESK3 pagou R$ 1,20 em dividendos nos últimos 12 meses, o preço teto seria: R$ 1,20 ÷ 0,06 = R$ 20,00. Este valor é apenas uma referência educativa e não reflete dados reais atuais.

O método não considera outros fatores como endividamento ou perspectivas de crescimento. É uma ferramenta entre várias na análise fundamentalista.
