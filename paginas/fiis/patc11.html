Sobre FII Patria (PATC11)

O FII Patria, negociado sob o ticker PATC11, é um fundo de desenvolvimento imobiliário gerido pela Patria Investimentos. O fundo tem como foco a aquisição e desenvolvimento de empreendimentos imobiliários, buscando gerar valor através de projetos estruturados no setor.

Com uma estratégia voltada para o longo prazo, o PATC11 distribui rendimentos mensais aos cotistas, sendo uma alternativa para investidores que buscam exposição ao mercado imobiliário de forma diversificada. A gestão profissional busca identificar oportunidades que aliem potencial de valorização e geração de caixa.

Como Calcular o Preço Teto de PATC11 pelo Método Bazin

O Método Bazin, criado pelo investidor Décio Bazin, é uma abordagem educativa para estimar um preço teto de um ativo com base nos dividendos distribuídos. A premissa é que o investidor define uma taxa de retorno desejada (neste caso, 10% ao ano) e calcula o preço máximo a pagar.

Fórmula: Preço Teto = Dividendos dos últimos 12 meses ÷ Taxa Bazin (10%)

Exemplo hipotético para ilustração — valores fictícios:

Suponha que o PATC11 tenha distribuído R$ 8,00 por cota nos últimos 12 meses. Aplicando a fórmula: Preço Teto = R$ 8,00 ÷ 0,10 = R$ 80,00. Este valor é meramente ilustrativo e não reflete dados reais do fundo.

O método não considera outros fatores como valor patrimonial ou perspectivas futuras, sendo apenas uma ferramenta educativa entre várias disponíveis.

Rendimentos Mensais do PATC11

O FII Patria possui uma política de distribuição de rendimentos mensais, geralmente pagos aos cotistas com base no resultado do fundo. Os valores distribuídos variam conforme a performance dos empreendimentos e as despesas do fundo.

Para pessoas físicas, os rendimentos de FIIs são isentos de Imposto de Renda, desde que respeitados os limites estabelecidos pela legislação (até determinado valor por mês). Historicamente, o PATC11 tem mantido uma regularidade nas distribuições, mas não há garantia de valores futuros.

Recomenda-se acompanhar os comunicados oficiais do fundo para verificar os rendimentos declarados mensalmente.
