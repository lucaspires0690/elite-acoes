Como Calcular o Preço Teto de SANB11 pelo Método Bazin

O Método Bazin, criado pelo investidor Décio Bazin, é uma abordagem educativa que ajuda o investidor a definir um preço máximo (teto) para comprar um ativo com base nos dividendos distribuídos. A lógica é simples: o investidor define uma taxa de desconto desejada — no caso, 10% ao ano — e calcula o valor justo.

Fórmula: Preço Teto = Dividendos dos últimos 12 meses ÷ 0,10

Exemplo hipotético para ilustração — valores fictícios:
Suponha que SANB11 tenha distribuído R$ 12,00 por cota nos últimos 12 meses. Aplicando a fórmula: R$ 12,00 ÷ 0,10 = R$ 120,00. Esse seria o preço teto segundo o método. Lembre-se: este é apenas um exemplo educativo; os dados reais devem ser consultados no app.

O método não considera outros fatores de valuation e serve como ferramenta de referência inicial. Cada investidor deve fazer sua própria análise.

Rendimentos Mensais do SANB11

O SANB11 distribui rendimentos mensalmente, seguindo a política de fundos imobiliários. Os valores são definidos com base no resultado do fundo e podem variar a cada mês. Para pessoas físicas, os rendimentos de FIIs são isentos de Imposto de Renda, desde que respeitados os limites legais.

Historicamente, o fundo mantém uma trajetória de distribuições regulares, mas não há garantia de valores futuros. Consulte o app Elite Ações para acompanhar o histórico completo de rendimentos.
